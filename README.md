# Nistikon — Support

Support and legal pages for **Nistikon — Orthodox Calendar**, an offline Orthodox fasting calendar and prayer-rule companion for iOS.

All three pages are trilingual (English, Português, Español): each page carries
`[data-lang]` sections for all three languages and `site.js` shows one, driven
by the `#portugues` / `#espanol` URL fragments, the language tabs in the nav, a
stored preference, and finally the browser language. Without JavaScript the
three languages render stacked — legal content is never hidden. The app's
Settings deep-links carry the fragment matching the in-app language.
