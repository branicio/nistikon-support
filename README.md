# Nistikon — Support

Support and legal pages for **Nistikon — Orthodox Calendar**, an offline Orthodox fasting calendar and prayer-rule companion for iOS and Android.

All three pages are available in seven languages (English, Português, Español,
Français, Italiano, Ελληνικά, Deutsch): each page carries `[data-lang]` sections
for all seven languages and `site.js` shows one, driven by the `#portugues` /
`#espanol` / `#francais` / `#italiano` / `#ellinika` / `#deutsch` URL fragments,
the language tabs in the nav, a stored preference, and finally the browser
language. Without JavaScript the seven languages render stacked — legal content
is never hidden. The app's Settings deep-links carry the fragment matching the
in-app language.

`impressum.html` is the legal notice (Impressum, § 5 DDG), added 2026-11-03: like the other pages it carries `[data-lang]` sections for all seven languages, switched by the same language tabs and fragments.
`fonts/` self-hosts the four Google Fonts families (latin, latin-ext, greek, greek-ext; OFL texts in `fonts/LICENSES.txt`), so no page requests anything from Google.
