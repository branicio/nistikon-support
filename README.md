# Nistikon — Support

Support and legal pages for **Nistikon — Orthodox Calendar**, an offline Orthodox fasting calendar and prayer-rule companion for iOS and Android.

All three pages are available in six languages (English, Português, Español,
Français, Italiano, Ελληνικά): each page carries `[data-lang]` sections for all
six languages and `site.js` shows one, driven by the `#portugues` / `#espanol` /
`#francais` / `#italiano` / `#ellinika` URL fragments, the language tabs in the
nav, a stored preference, and finally the browser language. Without JavaScript
the six languages render stacked — legal content is never hidden. The app's
Settings deep-links carry the fragment matching the in-app language.
